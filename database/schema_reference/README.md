# Schema Reference

The Atlas data model is documented in [`docs/design/database-schema.md`](../../docs/design/database-schema.md):
entities, conventions, the ER diagram, indexing, audit logging, integrity rules and the
migration history (0001–0025). The models in `database/models/` and the Alembic chain in
`database/migrations/versions/` are the source of truth; the design doc is kept in step with them.
